A clean full-stack starter running on
[vinext](https://github.com/cloudflare/vinext), with optional Cloudflare D1 and
Drizzle support.

<img width="2940" height="1602" alt="a06351ba046ef97fc8020a4f6e015ac2" src="https://github.com/user-attachments/assets/2717d461-099e-4766-afbc-cf1475689d7e" />


## Prerequisites

- Node.js `>=22.13.0`

## Quick Start

```bash
npm install
npm run dev
npm run build
```

This starter does not use `wrangler.jsonc`.
