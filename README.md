# 鸿运抽奖台

鸿运抽奖台是一个适合年会、聚会和现场活动使用的网页抽奖工具。打开网页即可开始抽奖，无需注册、登录、手机号或短信验证。

## 功能介绍

- 从 `1—51` 中随机抽取幸运号码。
- 共设 10 轮，每次点击揭晓 1 个号码。
- 已中奖号码不会再次出现，确保 51 个席位互不重复。
- 自动显示当前轮次、抽取进度和全部中奖名单。
- 当前轮抽满后自动进入下一轮，全部抽完后自动结束。
- 支持一键清空中奖结果并重新开始。
- 提供适合大屏展示的喜庆界面，并兼容电脑和手机浏览器。

## 抽奖规则

各轮中奖人数依次为：

| 轮次 | 第 1 轮 | 第 2 轮 | 第 3 轮 | 第 4 轮 | 第 5 轮 | 第 6 轮 | 第 7 轮 | 第 8 轮 | 第 9 轮 | 第 10 轮 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 人数 | 8 | 8 | 6 | 8 | 7 | 6 | 2 | 2 | 2 | 2 |

总计 `51` 人。抽奖必须按轮次顺序进行，尚未开始的轮次不能提前抽取。

## 使用方法

1. 打开网页，点击“开启第一份好运”。
2. 等待号码滚动结束，查看本次中奖号码。
3. 继续点击抽奖按钮，直到当前轮名额抽满。
4. 网页会自动进入下一轮；全部 10 轮结束后，完整结果会显示在“好运高光榜”中。
5. 如需重新抽奖，点击页面右上角“重新开始”并确认清空。

> 抽奖结果仅保存在当前页面中。刷新或关闭页面，以及点击“重新开始”，都会清空现有结果。

## 本地运行

### 环境要求

- Node.js `22.13.0` 或更高版本
- npm

### 启动步骤

```bash
npm install
npm run dev
```

终端显示本地访问地址后，在浏览器中打开该地址即可使用。

## 修改号码和轮次

轮次人数配置位于 `app/page.tsx`：

```ts
const ROUND_COUNTS = [8, 8, 6, 8, 7, 6, 2, 2, 2, 2];
const TOTAL = 51;
```

- `ROUND_COUNTS` 表示每轮需要抽取的人数。
- `TOTAL` 表示可参与抽奖的号码总数，号码从 `1` 开始。
- 修改时应确保 `ROUND_COUNTS` 中所有数字之和等于 `TOTAL`。

```text
  layout.tsx        页面布局和分享信息

```

## 技术说明

项目使用 React、TypeScript、Tailwind CSS、Vite 和 vinext 构建。抽奖逻辑在浏览器端运行，不依赖数据库、登录系统或短信服务。
