# 鸿运抽奖台

一个无需登录、无需短信验证的纯前端抽奖网页。号码范围为 1—51，共 10 轮；
每次抽取一个不重复的幸运号码。

## Prerequisites

- Node.js `>=22.13.0`

## Quick Start

```bash
npm install
npm run dev
npm run build
```

This starter does not use `wrangler.jsonc`.

抽奖结果保存在当前页面内存中，刷新页面或点击“重新开始”会清空结果。
